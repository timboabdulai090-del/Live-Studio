# Live Studio Privacy Policy Website

A responsive static HTML/CSS website for the Live Studio app by Top Games Studio.

## Files
- `index.html` — website content and privacy policy
- `style.css` — responsive design and print styles

## Preview locally
Open `index.html` in your web browser.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new **public** repository, for example `live-studio-privacy`.
2. Upload `index.html`, `style.css`, and this `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to publish the site. The URL will look like:
   `https://YOUR-GITHUB-USERNAME.github.io/live-studio-privacy/`

## Before publishing
Review the privacy policy against the app's actual data practices, permissions, ads, analytics, and third-party SDKs. Do not claim practices that are not true. Update the effective date and policy as needed.
